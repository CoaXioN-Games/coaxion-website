	//
	// Roles Localization HOWTO:
	//
	// The Credits Dialog supports localized role descriptions using the following
	// KeyValues naming convention:
	//
	//	roles_<language>
	//
	// For example:
	//
	//	roles_russian
	//	roles_french
	//	roles_german
	//
	// The dialog first looks for a role description matching the user's current
	// Steam language. If a localized entry is not available, it falls back to:
	//
	//	roles_english
	//
	// If neither the user's language nor the English entry exists, the dialog
	// falls back to the legacy `roles` key.
	//
	// Example:
	//
	//	"roles_english"	"Developer"
	//	"roles_russian"	"Разработчик"
	//	"roles_german"	"Entwickler"
	//	"roles"		"Developer" // Legacy fallback
	//
	// To add support for a new language, add a `roles_<language>` entry using
	// the language identifier returned by Steam's GetCurrentGameLanguage().
	//
	// The lookup order is:
	//
	//	1. roles_<current Steam language>
	//	2. roles_english
	//	3. roles
